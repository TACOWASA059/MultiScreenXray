# MultiScreen X-ray

MultiScreen X-ray adds up to eight independent X-ray windows beside your normal Minecraft view. Each window can use a different block list, entity list, preset, visual style, scan range, size, and position.

Use the modern in-game settings screen to browse blocks and entities by icon and name, search registry entries, select common tags, or enter modded IDs directly. Built-in presets cover ores, valuables, Nether targets, structures, and entities.

**Controls:** F8 adds a window, Shift+F8 removes one, and F9 opens settings.

The mod runs entirely on the client and works in singleplayer and multiplayer. Server anti X-ray systems may limit hidden block data. Follow each server's rules.
