# MultiScreen X-ray

Run several independently configured X-ray views next to the normal game window.

- Up to eight saved X-ray windows
- Visual block and entity selectors with icons, names, and search
- Registry ID, tag, and wildcard selectors
- Ores, valuables, Nether, structures, and entities presets
- Minecraft block textures, outlines, fluids, entities, and hand rendering
- Saved filters, options, window size, and position per screen
- Client side multiplayer support

Press **F8** to add a window, **Shift+F8** to remove one, and **F9** for settings. Server anti X-ray systems may limit hidden block data; follow the rules of the server you join.
